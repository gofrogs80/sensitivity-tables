# Sensitivity Tables

Rental property underwriting tool: set your assumptions once, then stress-test
the deal — build a two-way sensitivity table on any two inputs, or view a
tornado chart ranking every input by how much it swings the metric you care
about (monthly cash flow, cash-on-cash return, cap rate, or NOI).

Static, single-page HTML/CSS/JS — no build step, no dependencies.

## Local development

Just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

## Deployment

Deployed on Vercel as a static site (see `vercel.json`).
